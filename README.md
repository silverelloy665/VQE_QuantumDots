# VQE_QuantumDots
This Qiskit pipeline calculates the ground-state energy of Graphene Quantum Dots using the 6-31g(d,p) basis set. Following active space reduction and Jordan-Wigner mapping, it tests DexcG, PCU2, UCCSD, and k-UpCCGSD ansätze. The system utilizes an ADAM optimizer with zero-initialization for optimal convergence and precision.
